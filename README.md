# Weather Diary 

**Автор:** Михайлов Сергей

## Описание программы
Weather Diary — это десктопное приложение для ведения дневника погоды. Программа позволяет:
- Добавлять записи о погоде (дата, температура, описание, наличие осадков)
- Просматривать все записи в табличном виде
- Фильтровать записи по дате или по температуре (выше указанного значения)
- Сохранять данные в JSON файл и загружать из него
- Автоматически сохранять записи при добавлении

## Требования
- Python 3.7 или выше
- Стандартные библиотеки: tkinter, json, datetime, os
